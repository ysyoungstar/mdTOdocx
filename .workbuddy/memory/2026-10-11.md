## 全量功能检查与缺陷修复（mdTOdocx）

**任务**：检查 index.html 所有按钮是否可用、项目功能是否正常。

**方法**：三服务实跑（pandoc server :3030 / serve-pages.py :8080 / convert-server.py :3040）
+ 真实 Chrome 用 CDP 驱动逐一点击，共 72 项断言，最终 72/72 通过。

**发现并修复的 3 个真实缺陷**：
1. `js/app.js` `bindSplitter()` 只绑定 `#splitter`，反向模式的 `#splitter-reverse` 完全不能拖拽
   → 改为遍历两个分隔条共用同一套拖拽逻辑（`dragging` 由 boolean 改为元素引用）。
2. `js/app.js` 快捷键 Ctrl+S 直接调用 `convert()`，在「Word/HTML → MD」模式下会错误执行反向的转换
   → 改为调用 `onPrimaryAction()`，按当前方向分发。
3. `js/options.js` 里 `restore()` 已实现但从未被调用，选项只写 localStorage 不读回
   → `init()` 中 `renderForm()` 之后补上 `restore()`。
   （`resetToDefaults()` 仍无 UI 入口，待需要时再加按钮。）

**清理的冗余**：
