# Markdown 转 Word 示例文档

> 本文件用于验证 mdTOdocx 的排版效果：标题、表格、代码块、引用、列表与数学公式。

## 一、文本格式

支持 **粗体**、*斜体*、~~删除线~~、`行内代码` 以及 [超链接](https://pandoc.org)。

## 三、表格

| 功能 | 说明 | 状态 |
| --- | --- | :---: |
| 目录 | 由 toc 选项生成 | 支持 |
| 模板 | reference.docx | 支持 |
| 图片 | 通过 files 字段注入 | 支持 |
| 章节编号 | number-sections | 支持 |

## 四、代码块

```javascript
// 代码高亮样式可在右侧“转换选项”中切换
function toDocx(markdown) {
  return pandoc.convert(markdown, { to: 'docx' });
}
```
